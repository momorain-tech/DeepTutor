# 第 4 课 · 病、症、证与四诊 {#symptom-disease-pattern-start}

本课练习区分信息与结论。你需要能解释病、症、证的层次，列出四诊名称，并把带诊断标签的句子还原为可以核对的观察。

## 三个字，三个不同问题 {#three-levels}

“症”通常指具体的症状、体征等表现；“病”着眼于疾病过程的认识；“证”是中医对疾病过程中一定阶段病理状态的概括。具体的证候判断需要综合资料，不是给一个症状换个更专业的名字。

教学例子：“我这周有几次胃部不适”是对表现和时间的描述；“因此我一定属于某证”已经多走了一步。中间还缺具体表现、变化过程和专业评估。这里不要求给这个虚构人物作诊断，而是找到推理缺口。

中医基础教学把病、证、症的关系和辨证论治作为专门内容；入门学习先掌握它们并非同义词。[参见《健康教育中医药基本内容》关于疾病认识的部分](https://www.haishu.gov.cn/art/2024/4/22/art_1229790084_58995062.html)。

## 四诊是收集信息的方法，不是一张图片 {#four-examinations}

望、闻、问、切是四诊的名称。其中“闻”包含听声音、嗅气味等内容；“切”不只是在日常语言里说“碰一下”。专业诊察有其知识和技术要求，不能把四诊理解成四个自动判定按钮。

学习者在日常沟通中能做的，是准确描述自己知道的事实，并说明不知道什么。不要为了填满一张表而猜测脉象、舌象或证型。对图片、单次读数或一个表现的解释，需要放在完整背景里。

本课不教授远程自诊。四诊和辨证内容的范围可在[北京中医药大学考试大纲的中医诊断学部分](https://yanjiusheng.bucm.edu.cn/docs/2024-10/7832c8f9553b4a5dbc7f95267cc2027f.pdf)核对。

## 证候判断需要语境与过程 {#context-before-label}

辨证要对资料进行综合分析；论治是在相应判断基础上讨论治疗。理解两者的关系，可以防止从一个标签直接跳到某个产品。

同病异治与异病同治也是这一理论中常见的说法：它们提醒学习者，疾病名称与证候层次不能机械地一一对应。理解这个概念，并不意味着可以忽略已经明确的疾病诊断或自行调整治疗。

改写练习：将“我肯定是某证，要马上买药”改成“最近出现了什么、从什么时候开始、怎样变化、有没有影响生活；我希望请医生解释可能的原因与下一步”。改写后保留了事实和问题，减少了未经确认的结论。

## 先回忆，再核对 {#symptom-disease-pattern-check}

请解释：一个症状为什么不足以等同于一个证？四诊的“闻”是否只指闻气味？用“我观察到……”和“我想确认……”各写一句话。

参考：证是对阶段性状态的综合概括；闻诊不只涉及嗅觉；观察句报告事实，提问句承认待确认之处。本课练的是描述能力，而不是给自己选一个证型。
