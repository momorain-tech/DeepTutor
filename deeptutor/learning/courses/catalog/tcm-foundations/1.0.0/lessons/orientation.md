# 第 1 课 · 从哪里开始学中医 {#orientation-start}

读完这节课，你要能解释整体观念，区分理论、观察和疗效结论，并说清自己希望学会什么。先想一个问题：你是想听懂术语、理解传统思维，还是正被某个健康问题困扰？前两项适合在课程中学习；具体健康问题需要另外得到专业评估。

## 先确定学习任务 {#learning-scope}

本课把中医作为有特定历史、概念和实践方法的医学体系来认识。入门学习的第一项能力，是读懂一句话在其理论语境中的意思。第二项能力，是知道还缺哪些资料才能判断它是否适用于某个人。

例如，读懂“阴阳”这个词，可以帮助你理解后面的教材；但能说出定义，并不等于能判断一个人的身体状况。课程练习检查的是理解和表达，不授予诊疗资格。遇到“学完三课就能给全家开方”的广告，可以先把“学过概念”和“能独立诊疗”这两项主张拆开。

试着写一句个人学习目标：“我希望能向家人解释一个常见术语，并把查到的依据一起给他看。”这个目标有可展示的结果，比“全面精通中医”更适合第一阶段。

## 整体观念：把问题放回联系中 {#whole-view}

中医基础理论中的整体观念，关注人体内部的联系，也关注人与自然、社会环境的联系。学习这个概念时，重点是“还需要了解哪些背景”，而不是给所有现象找同一个原因。[教学范围可核对《健康教育中医药基本内容》第一部分](https://www.haishu.gov.cn/art/2024/4/22/art_1229790084_58995062.html)。

教学例子：小林说自己这周白天很困。只记录“困”留下的信息很少；再了解作息变化、工作安排、近期身体不适和正在使用的药物，可以让描述更完整。这是在练习补充背景，尚未证明其中哪一项是原因。

反例：“整体观念说明任何不舒服都是同一处出了问题。”这句话把“存在联系”换成了“只有一个原因”。两者不同。联系需要进一步分析，不能靠一个理论标签直接得出个人诊断。

## 给一句话标明层次 {#claim-types}

本课程用三类标签帮助阅读：

| 标签 | 例子 | 下一步要问 |
|---|---|---|
| 理论表述 | 某教材用阴阳关系解释现象 | 这个词怎样定义、比较条件是什么？ |
| 观察记录 | 我昨晚比平时晚睡两小时 | 记录是否准确，还有什么背景？ |
| 疗效主张 | 某种方法能改善某种疾病 | 针对谁、与什么比较、获益和风险怎样？ |

这张表是课程编写的阅读工具，不是临床分类标准。一句话也可能混有多层内容，应拆开阅读。传统理论的表述与某项治疗是否有效，是不同的核对任务；现代研究也需要按具体方法和健康问题分别讨论。[可参考 NIH 对中医相关方法及研究的分类介绍](https://www.nccih.nih.gov/health/traditional-chinese-medicine-what-you-need-to-know)。

## 先回忆，再核对 {#orientation-check}

合上上文，用三句话回答：整体观念在提醒你补什么信息？“这杯茶让我睡好了”属于哪一层？能否仅据它给别人推荐治疗？

参考表达：整体观念提醒我关注背景和联系；“让我睡好了”把一次经历连到了效果判断，还需要区分观察与原因；一个人的经历不足以决定别人该接受什么治疗。正确答案不要求使用相同措辞。

本课完成物：选一条你见过的健康说法，标出其层次，并写一个尚未回答的问题。可以使用虚构例子，不必提交个人健康信息。
