# 第 6 课 · 中药与产品信息：准备一张沟通卡 {#medicine-safety-start}

本课学习识别产品说法、整理用药信息和向专业人员提问。它不要求选择药品，也不提供剂量、疗程或自行配伍方法。

## 天然来源与使用风险是两个问题 {#natural-and-risk}

一种产品来自植物或被称为传统用品，并不能单独说明它对每个人都适用。中药使用也涉及药材辨识、质量、用量、使用方法和个体情况等因素。[卫生署的公共教育资料介绍了中药不良反应的不同来源](https://www.cmro.gov.hk/html/gb/useful_information/public_health/exhibit_boards/Adverse_Reactions_of_Chinese_Medicines.html)。

看到“纯天然，所以没有副作用”时，可先拆成两句：第一句在说来源，第二句在作安全保证。第一句即使属实，也不足以证明第二句。类似地，“很多人用过”不等于已知道某个人能否使用。

本课不把某类产品一概判定为有效、无效、安全或危险。需要核对的是具体产品、成分、使用条件，以及与个人情况相关的风险。

## 把完整信息交给专业人员 {#medication-card}

如果准备就诊或咨询用药，可先整理一张信息卡：

| 项目 | 可以准备什么 |
|---|---|
| 产品身份 | 准确名称、包装或说明书；成分不清就注明 |
| 实际使用 | 已经怎样使用、何时开始；按真实情况记录 |
| 其他用品 | 同时使用的处方药、非处方药、中药和补充剂 |
| 个人背景 | 已知过敏、不适反应、已有疾病及妊娠等相关情况 |
| 想问的问题 | 是否适合、是否可能相互影响、怎样按医嘱使用 |

这张卡是沟通工具，不是自行判断相互作用的算法。不要因为自己没找到某条相互作用，就推断一定没有。对成分不明的东西，承认未知比猜一个药名更有用。

## 专业建议要对应具体人和具体问题 {#professional-consultation}

他人的处方和网上流传的经验不能直接当作自己的使用方案。即使是熟悉的药材，也不宜自行决定增减、组合或长期使用；用药问题需要向有资质的医师、药师咨询。[卫生署《中药的安全使用》专门说明了自行使用验方和长期随意服药的问题](https://www.cmro.gov.hk/html/gb/useful_information/public_health/feature_articles/Safe_Use_of_Chinese_Medicines.html)。

教学例子：朋友给你一包无完整标签的“调理粉”。合适的课程回答是“目前无法核对成分和使用条件，先保留包装并向专业人员确认”，而不是猜它属于哪一类体质用品。已有治疗方案也不应仅因一条宣传语就自行停止或替换。
