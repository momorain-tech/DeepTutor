# 第 3 课 · 脏腑、气血津液与经络 {#body-language-start}

这一课建立词汇地图。读完后，你应能说明术语所在的理论语境，区分几个基本概念，并避免把同名词直接当作同一个检查指标。

## 脏腑名称：先读完整语境 {#zang-fu}

藏象学说把体内的功能活动、外在表现以及它们的联系组织起来。教材中的脏腑概念涉及功能联系，不能只看到名称，就把全部含义缩成现代解剖学的某一个器官。[安徽中医药大学的藏象教学介绍展示了从解剖基础和功能联系共同理解术语的做法](https://lcxy.ahtcm.edu.cn/info/1113/33281.htm)。

五脏通常指心、肝、脾、肺、肾；六腑通常指胆、胃、小肠、大肠、膀胱、三焦。先识别这些名称，不要求在本课背完各自的全部生理、病理和配属关系。

教学例子：读到一段谈“脾”的中医文字时，先问作者在讨论哪项功能和哪些表现，再去查教材释义。不能仅凭这个词，就断言现代检查中的脾脏发生了什么变化。反过来，也不能把一份器官检查结果直接替换为完整的中医证候判断。

## 气、血、津液：区分概念，记住联系 {#qi-blood-fluids}

在中医基础理论中，气用于描述生命活动的物质与功能等内容；血与濡养等功能相关；津液是体内正常水液的总称。这些是本课程使用的入门解释，详细定义和相互关系需继续学习专业教材。

它们在理论上相互联系，却不等于彼此相同。把“气”直接理解成吸入的空气，把“血”相关的一切表述直接等同于血常规数值，都会损失原有语境。传统概念与现代生理指标可以分别研究，不能未经论证就建立一对一替换表。

制作三张词卡：正面写名称，背面写“在理论里谈什么”和“不能直接等同于什么”。例如，“津液——正常水液的概念；不是任何单项检验数值的别名”。[气、血、津液的学习范围见北京中医药大学考试大纲相关章节](https://yanjiusheng.bucm.edu.cn/docs/20200915120435519822.pdf)。

## 经络：先知道它在理论地图中的位置 {#meridians}

经络学说描述联系脏腑、肢节等的系统；专业学习还包括经脉组成、循行和相关应用。它在基础理论中是一组需要单独学习的概念，不能直接改名为血管或神经网络。[可核对北京中医药大学教学大纲“经络”章列出的内容](https://jxjyxb.bucm.edu.cn/ibucm/zhengwen/update/1_4b.htm)。

认识这个词，不等于已经掌握穴位定位、针刺深度或技术操作。看到某张图片，也不能据此在自己或他人身上尝试侵入性操作。本课的学习任务只是把术语放对位置。

## 先回忆，再核对 {#body-language-check}

请给朋友解释：“中医教材里的脏腑概念，为什么不能只按同名器官理解？”再任选气、津液、经络中的一项，写一句定义范围和一句不能直接替换的现代概念。

参考：要同时看功能、表现和联系；不同体系中的同名或相近词，不能省略解释就互相替换。能说明区别，比机械复述术语清单更接近本课目标。
