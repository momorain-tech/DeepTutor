# 第 7 课 · 怎样读一条健康信息 {#health-information-start}

这一课把“看起来有道理”改成一组能核对的问题。你将完成一张健康说法核查卡，不需要先学统计计算。

## 先找到最初的出处 {#trace-source}

看到一条健康说法，先找作者、发布时间、原始页面或研究，以及发布者是否在销售相关产品。转发次数、医生形象和机构标志都不能替代出处核对。

把“专家说有用”继续追问为：是哪位作者？说的是哪种方法？原文针对什么问题？如果只找到广告截图，核查卡就写“尚未找到可核对的原始材料”。这不是证明它一定错误，而是如实记录目前证据不足以供你判断。

遇到一篇论文时，可从它本身了解研究问题，而不只依赖标题或新闻摘要。[NIH 的研究阅读入门页解释了回到科学论文来源的重要性](https://www.nccih.nih.gov/health/know-science/how-to-make-sense-of-a-scientific-journal-article/overview)。

## 问清研究在比较什么 {#study-comparison}

本课程使用五个核查问题：研究了谁？具体做了什么？与什么比较？观察了什么结果、多久？有什么不确定性和风险？这五问是课程编写的阅读框架，不是给研究打总分的正式量表。

教学例子：某帖子称“十位使用者一个月后感觉更轻松”。这提供了一些体验信息，但还没有说明没有使用的人怎样，也可能同时发生其他变化。它不能单独证明效果由该方法造成。

一个有比较组的研究也不会自动回答所有问题。还要看比较方式、研究人群和结果指标是否对应原先的主张。研究了某种方法的某个用途，不能跳成“整类方法适用于所有健康问题”。

## 把结论写到证据允许的位置 {#limited-conclusion}

对中医相关方法的研究，应该区分具体方法和具体健康问题，而非只作“全部有效”或“全部无效”的总判断。[NIH 的中医公共教育页面分别介绍了不同方法的研究与安全问题](https://www.nccih.nih.gov/health/traditional-chinese-medicine-what-you-need-to-know)。

把“已经证实人人有效”改写为：“这份材料涉及某类人群、某种方法和某项结果；我还需要核对比较方式、风险与是否适用于自己的情况。”如果原始材料根本没找到，就不能写成“研究已经证实”。

| 核查卡 | 填写方式 |
|---|---|
| 原说法 | 忠实写出主张，不替它增强语气 |
| 可核对来源 | 链接、作者、日期；找不到就注明 |
| 支持了什么 | 人群、方法、比较、结果、时间 |
| 尚不能推出什么 | 因果、普遍适用、长期安全等仍待核对的部分 |
| 下一步 | 继续查证或向专业人员提问 |

## 先回忆，再核对 {#health-information-check}

有人说“我用了有效，所以你可以停掉原来的治疗”。请分别指出体验、推广给别人和改变治疗这三个层次。

参考：个人体验可以如实记录；能否推广需要额外研究；个人治疗安排还需要专业评估。仅凭转发量、单次经历或理论解释，都不能跨过这几个判断步骤。
