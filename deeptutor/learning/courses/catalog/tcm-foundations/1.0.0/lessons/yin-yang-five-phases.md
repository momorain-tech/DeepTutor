# 第 2 课 · 阴阳五行怎样读 {#yin-yang-five-phases-start}

本课先学会“在什么条件下比较”，再认识阴阳关系和五行分类。目标是能解释模型的用法，不是根据天气、口味或性格给自己下结论。

## 阴阳属性需要比较语境 {#relative-properties}

在传统理论中，阴阳是描述相关事物或同一事物两方面关系的概念。入门时，可以用明暗、动静等配对理解“相对而言”这一点。先明确比较的是哪个方面，再讨论其阴阳属性。

教学例子：以光照比较，同一天里向阳的一面与背阴的一面可以形成一组关系；如果换成时间变化，就必须重新说清比较条件。“某个物体永远只属于一方”的说法忽略了参照条件。

类比只帮助记住比较方法，并不能证明人体内某种具体机制。一份检查结果也不能直接换算成“阴值”或“阳值”。本课没有给任何人作体质判定。

## 关系比两个标签更重要 {#yin-yang-relations}

中医教学通常讨论阴阳的对立制约、互根互用、消长平衡与相互转化等关系。这里先理解四个问题：两方面怎样相互限制？是否相互依赖？比例怎样变化？在什么条件下发生转变？[术语与课程范围见北京中医药大学《中医基础理论》教学大纲的第一章](https://jxjyxb.bucm.edu.cn/ibucm/zhengwen/update/1_4b.htm)。

“消长”强调变化；“转化”强调在一定条件下性质发生转变。不要把两者简单当成同义词。记忆时可以先写关系名，再写一句不涉及治病的解释。

小练习：把“阴阳就是把人分成两种”改写得更准确。参考：“阴阳用于分析一定语境中的关系，不能把每个人固定分成两类。”这个改写保留了概念的相对性。

## 五行是一套分类与关系模型 {#five-phases}

五行用木、火、土、金、水这些名称组织传统理论中的归类和关系。学说中的名称并不是说人体由五种日常材料简单拼成。理解“归类”与“材料成分”有别，比先背一张很大的对应表更重要。

相生与相克是其中两类关系。常见的相生次序为木、火、土、金、水，再回到木；相克次序为木、土、水、火、金，再回到木。这里是在识读理论，不把这套次序作为个人用药或食物搭配规则。[范围和关系名称可核对本科教学大纲及研究生考试大纲的“阴阳五行”部分](https://yanjiusheng.bucm.edu.cn/docs/2024-10/7832c8f9553b4a5dbc7f95267cc2027f.pdf)。

反例：“一种食品颜色属某行，所以能治疗相应脏腑的疾病。”它从分类跳到了疗效，需要另外的证据，不能由对应关系直接推出。
