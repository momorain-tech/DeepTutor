# 第 5 课 · 起居、饮食与情志：先把背景记清楚 {#daily-context-start}

本课的产出是一份虚构的三天记录和一个可检查的小计划。你可以完全使用下面的例子，不需要在平台提交个人健康数据。

## 日常因素提供背景 {#daily-factors}

中医养生教育常从情志、饮食、起居、运动等方面讨论日常生活，并关注人与环境的联系。学习这些内容时，可以先列出“哪些背景值得了解”，不急着给每个因素赋予确定的病因解释。[《健康教育中医药基本内容》列出了这些健康教育范围](https://www.haishu.gov.cn/art/2024/4/22/art_1229790084_58995062.html)。

一般健康素养也重视合理膳食、适当活动、充足睡眠和心理健康。这里不提供适用于所有人的统一作息时刻、运动强度或进补食谱；个人限制和既有医嘱会影响选择。[核对国家卫生健康委正式发布的《基本知识与技能（2024年版）》第 25—43 条](https://wsjk.gansu.gov.cn/wsjk/c118353/202406/173933066/files/d86b92027c12468fbbd6fdb6ada75e5f.pdf)。

## 记录事实，另放解释 {#context-log}

下面是编写的教学例子，不是一份病历：

| 日期 | 可观察的事实 | 当时背景 | 尚待确认 |
|---|---|---|---|
| 第一天 | 午后比平时更困 | 前夜加班，入睡时间推迟 | 这种变化是否反复出现？ |
| 第二天 | 午后仍困 | 作息与第一天接近 | 是否还有遗漏背景？ |
| 第三天 | 自觉较前一天精神 | 工作安排改变 | 不能仅据一天变化确认原因 |

记录时尽量分清发生时间、持续或重复情况、对生活的影响，以及同时发生的变化。不知道的项目就写“不清楚”。涉及症状时，记录帮助沟通，不是延后就医的观察任务。

反例：“第三天做了某件事，所以它治好了前两天的问题。”这个结论把先后发生当成因果证明，忽略了其他变化和自然波动。

## 让小计划可执行、可回看 {#small-plan}

课程里的计划练习针对日常安排，不是治疗试验。先选择一个在自己条件下可行的目标，再说明做什么、怎样记是否完成、什么时候回看。不要把“坚持得越猛越好”作为进步标准。

教学示例：“接下来三天，我在晚间安排次日待办，记录是否完成；三天后回看这个安排是否可执行。”它的结果是行为是否完成，不是保证某个健康指标一定改善。

如果计划涉及用药、明显身体不适、已有疾病限制或专业人员的治疗安排，应先沟通，而不是为了完成课程任务自行改变。一次计划未完成，先找阻碍，再调整目标大小，不用立即给自己贴体质或意志力标签。

## 先回忆，再核对 {#daily-context-check}

请在表中找出一条事实和一个未知项。再把“从明天起一定彻底改变生活”改为一个三天内可以核查是否完成的安排。

参考：事实应是当时记录到的变化；未知项不要补成诊断；小计划应写具体行为和回看时间，不能承诺治好疾病。完成后，说说这个计划的可执行性，还不能说明什么。
