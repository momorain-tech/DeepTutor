# 中医入门课程：编写说明

本目录是基于 PR #6 课程契约编写的首门内容草稿。`1.0.0` 当前登记为 `draft`，不会出现在公共课程目录，也没有填写虚构的专业审核人。

## 受众与学习结果

受众已由用户确认为没有医学背景的成年人：理解基本概念、辨别健康信息，不教自行诊断开方。课程帮助学习者读懂基础术语、区分理论表述与具体疗效结论、整理就医沟通信息。它不是中医专业教材、执业培训或诊疗工具。

学完后应能完成三项任务：

1. 用自己的话解释基础概念，并指出概念成立的语境。
2. 对一条健康信息找出处、辨认论据、写出尚不能推导的结论。
3. 把自己的观察整理为事实、时间线和问题，交给专业人员判断。

## 课程安排

| 单元 | 课时 | 重点 | 学习产出 |
|---|---|---|---|
| 一 · 建立概念地图 | 1. 从哪里开始学中医 | 整体观念、学习边界、三类表述 | 给一句话标明它在说什么 |
| | 2. 阴阳五行怎样读 | 相对性、关系、分类模型 | 解释比较条件，识别跳步推断 |
| | 3. 脏腑、气血津液与经络 | 术语语境、功能联系 | 一张区分概念的词卡 |
| | 4. 病、症、证与四诊 | 信息、判断与结论的层次 | 把诊断标签改写成观察事实 |
| 二 · 从日常经验到可用信息 | 5. 起居、饮食与情志 | 环境和生活背景、记录方法 | 一份虚构的三天记录与小计划 |
| | 6. 中药与产品信息 | 风险、完整用药清单、专业沟通 | 一份用药沟通卡 |
| 三 · 能查证，也能表达 | 7. 怎样读健康信息 | 原始来源、对照、结论边界 | 一张健康说法核查卡 |
| | 8. 把知识带进就诊沟通 | 时间线、提问、综合迁移 | 一段简明就诊说明 |

8 课，每课预计 20 分钟（阅读、回忆、练习合计），总计约 160 分钟；实际用时需学习者试读后调整。第 1、7 课设为未来公开样课，但 draft 状态下仍不对外公开。

## 教材与练习的对应

每课三个知识点，每个知识点两题，共 24 个知识点、48 道原创题。题目用于检查概念理解和信息处理能力，不作疾病诊断或疗效承诺。`concept`、`design` 知识点配开放题；客观题用于理解检查，开放题用于解释和迁移。阅读完成、练习结果与引擎判定的掌握度分别记录。

每课正文包含：可观察目标、核心解释、带推理过程的例子、一个反例、自检及其参考表达，以及对应来源。参考表达位于问题之后，建议先自行作答再往下阅读。所有人名和情境均为编写的教学例子，没有收集真实病历。

开放题提交会沿用 PR #6 的模型评分与用户计费。自检可先在纸上回答；参考表达属于教材，不会自动调用模型。评分规则评概念和论证，不要求复述固定措辞，也不把词语匹配当作医学判断。

## 来源与编审

`sources.json` 登记原始资料标题、机构、链接和核对位置。专业术语参考中医药大学教学资料；一般健康素养参考国家卫生健康委正式文件；用药与证据阅读参考卫生署和 NIH 的公共教育资料。教学例子、类比及核查表由课程编写，不是来源机构提供或认可的案例。引用不表示这些机构审核或背书本课程。

专业教学大纲只用于核对概念范围，不把入门课包装为考试辅导。部分教学资料发布较早，不能据其推定当前临床指南或执业要求。日后更新需重新核查链接和适用范围，尤其不要把征求意见稿当作正式文件。

当前 `manifest.review` 为 `null`，来源也未标记为已通过专业审核。来源检索和结构校验不能代替专业内容审校。正式发布前需要补齐实际编者署名、真实审核记录和试读反馈，再按契约发布及锁定内容版本。

优先审阅：第 2、3、4 课术语简化是否准确；第 5 课有无越过一般健康教育范围；第 6、8 课情境与提示是否恰当；48 题是否有歧义、开放题是否接受等价正确表达。课程不包含处方、剂量、穴位定位或自行操作教程。
